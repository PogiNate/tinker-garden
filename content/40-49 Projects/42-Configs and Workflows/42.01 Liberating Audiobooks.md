# Introduction

> Today I think is a good day to liberate my audiobooks from Audible.
> - Me to Michael Boyle, 17 Feb 2026

Audiobooks are great! The problem is that when you buy them they tend to be locked to a vendor. That is *less* great. What if the vendor wants to stop supporting them? What if they decide you can't listen to your own books any more? 

This is the problem with any "licensed"[^1] media. So I decided to see what I can do to liberate my audiobooks.

The main supplier of audiobooks is [Audible](https://www.audible.com/), which is a fully-owned subsidiary of Amazon.com. And to be fair, they have kept my books available for more than a decade. But _that's not good enough_. I still don't have control over them. 

# Requirements

For me to feel like I'm in control of my owned media, I need to meet the following requirements:

1. The media "lives" on hardware that I own
2. The media is accessible to anyone in my household
3. The media is stored in a way that is searchable and as easy to use as the locked down commercial version

# Tools Used

Doing some research, I found the following tools to meet the needs:

| Need                                | Tool                                                     | Note                                                 |
| ----------------------------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| Download audiobooks and remove DRM  | [Libation](https://getlibation.com/)                     | Open source, and suprisingly complete and effective! |
| Store and serve DRM-free audiobooks | [[32.02 Plex\|Plex]]                                     | always Plex, right? But with Caveats.                |
| Access Audiobooks                   | [Prologue](https://prologue.audio/)                      | For iOS                                              |

# Process

## 1. Liberate the audiobooks
This was honestly almost entirely painless. 
1. Download Libation and sign in to Audible. It will find all your audiobooks automatically
    1. Press the "Liberate" button and let it run.
    2. It will figure out DRM strategies and stuff. Pretty much by itself.
2. When Libation is done, open the directory where it stored the DRM-free audiobooks. Copy all your books to a place where your Plex Media Server can get to them.

## 2. Prepare Plex
Libation properly tags the files with all the metadata you could want, but Plex is not really configured to handle audiobooks. So we need to first give it a plugin to handle the metadata, then create a folder to store the audiobooks.

The plugin is fairly simple. Download it from the link above. Plex has a rarely-used Plug-in feature. Put the `audnexus.bundle` directory inside of Plex's plugin directory (on Linux it's in `AppData\Plex Media Server\Plug-ins`) and then restart the Plex Media Server. 

That done, you can create the new Library in Plex. 
1. In the General tab, choose "music". I know, I know.
2. In the "Add Folders" tab, add the right folder. 
3. In the "Advanced" tab, use "Plex Music Scanner" as the Scanner and hopefully "Audnexus Agent" shows up in the Agent box.
![[Pasted image 20260218123931.png]]

Then hit save and Plex will go to work scanning your files and adding them to the library. This will take a while.

## 3. Accessing Audiobooks

The Prologue player for iOS is designed to work with Plex. It handles audiobooks more seamlessly than Plexamp or other players. Simply sign into your Plex server in the app, and choose the library where you have audiobooks. This was entirely friction-free for me.

## Appendix A: Technical Details

Libation creates `.m4b` files when it frees your audiobooks. Each book is a _directory_ named after the book. Each chapter (or whatever segmentation the book uses) is a file. So if the book is called _A Hat Full of Sky_ you will have a directory named _A Hat Full of Sky_ with a number of `.m4b` files. 

Libation appends a unique identifier to the title of the book, to avoid problems arising from having multiple books with the same title. Which happens. So it looks more like this:

![[Pasted image 20260218123343.png]]

Each file is named `<book title> [UUID] - <chapter #> - <chapter title>.m4b`

You can of course modify these names and Libation provides you ways to do so.

an `.m4b` file is a _container_ file, and libation will use the highest quality codec available to store the audio data. AAC is common.
