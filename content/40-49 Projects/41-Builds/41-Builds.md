Builds are usually small hardware projects that also involve some software to be written. I generally do two types of 'builds':

1. Microcontrollers
    1. These are usually very small devices that can run a little bit of code to make fun things happen. 
    2. Most of the time I use CircuitPython for these builds.
2. <abbr title="single board computer">SBC</abbr> based builds
    1. Usually a Raspberry pi of some sort
    2. Full [[31.01 Linux|Linux]] support means these can use almost any tools or scripting languages when I build them out.
