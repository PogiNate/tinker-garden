I'm using [Basic Memory Cloud](https://app.basicmemory.com/notes) to help with this vault. This file contains instructions for the Basic Memory System to best use the vault. 

## Organization

This project is organized using the [[Johnny Decimal]] system. Each topic is designed to have its own place in the file system.


## Writing new notes

- Every new note or file goes into its correct [[Johnny Decimal]] location — never into the project root or an ad hoc folder.
- Before writing, check [[00-JDex]] (or the relevant category's JDex note, e.g. "40-49 Projects") to find the right area, category, and next available ID number.
- Follow the existing naming convention: a category folder is `AC-Name` (e.g. `41-Builds`); an item inside it is `AC.ID Name` (e.g. `41.01 Retro NFC Music Player`). Items with multiple files get their own `AC.ID Name` subfolder.
- If it's not clear which category or ID a new file belongs under, ask before writing rather than guessing.
- If something genuinely doesn't fit anywhere yet, stage it in `09-Inbox` instead of leaving it unfiled at the root, and flag it for proper categorization later.
