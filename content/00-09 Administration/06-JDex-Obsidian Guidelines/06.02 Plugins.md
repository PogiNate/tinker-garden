Using Johnny Decimal means that we can utilize a lot of [[Obsidian]] features, and Plugins make it easier. 

Here are the ones I'm using at the moment. 

- [Folder Notes](obsidian://show-plugin?id=folder-notes) To put an index or TOC note on each directory
- [Front Matter Title](obsidian://show-plugin?id=obsidian-front-matter-title-plugin) so that the aliasing of files is easy.
- [Iconic](obsidian://show-plugin?id=iconic) Because who doesn't love icons?
- [Pretty Properties](obsidian://show-plugin?id=pretty-properties) To make data about each file more parse-able
- [Style Settings](obsidian://show-plugin?id=obsidian-style-settings) A workhorse classic
- [vimrc Support](obsidian://show-plugin?id=obsidian-vimrc-support) so that my muscle-memory [[Vim]] shortcuts will work.
