Using [[Johnny Decimal]] means that we will have lots of directories that replicate the structure in the [[00-JDex|JDex]] itself. Fortunately [[Obsidian]] makes it easy to deal with this: inline display links are great!

So: ensuring that we have the folder notes plugin installed, I have created my structure in the JDex:

![[JDex Screencap.png]]

The `00 - JDex` folder note looks like this:

```markdown
# Full JDex
For ease of reference, I'm going to transclude all the JDex files here.

![[00-09 Administration]]

![[10-19 Hardware]]
```

and so forth. So all that is stored in that note is a list of transcluded references to the folder notes below it.

So for each _actual_ directory _outside_ the JDex I do the same thing but for _only_ that folder. 

So for `20-29 Programming Languages` folder note it has exactly one line:

```markdown
![[00-09 Administration/00 - JDex/20-29 Programming Languages/20-29 Programming Languages|Programming Languages]]
```

And that's all we need! Now it stays in sync with the JDex without worrying.
