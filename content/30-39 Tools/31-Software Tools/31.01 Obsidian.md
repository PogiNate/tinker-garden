# Obsidian

![[obsidian-logo-gradient.svg|100]]

Obsidian has been the system I've used to manage all my knowledge bases for a _long_ time now. As a tool it's well designed to work with both the [[07.01 Johnny Decimal System|Johnny Decimal]] system as well as [[Quartz]].


As of version `1.12`, Obsidian has a couple of very useful new tools: A CLI client for running Obsidian sessions and a _headless sync_ client for just keeping files in sync _without_ starting the Obisidan GUI. 

## Obsidian Sync

First off, Sync is a *paid* service, but isn't all that expensive. It provides end-to-end encrypted synchronization of your Obsidian Vaults. If you want to make your vaults accessible to other tools this used to involve opening the Obsidian GUI and syncing files. But now you can install the Headless sync client. 

### Headless Sync
actually it's pretty well explained in the official documentation: [headless sync client](https://help.obsidian.md/sync/headless)

## Obsidian CLI
I haven't poked around in this one much yet, but I think it's meant to be a way to let tools on your system interact with Obsidian beyond just reading markdown files. Documentation is here: [Obsidian CLI](https://help.obsidian.md/cli)

## Vim Mode
Obsidian has a great vim emulation mode based on CodeMirror. However it needs a helper to have a good config file behavior. 

I usually set up my config as follows:

```vimrc
"escape!
imap jk <Esc>

" Surround text with [[ ]] to make a wikilink
" NOTE: must use 'map' and not 'nmap'
exmap wiki surround [[ ]]
map [[ :wiki

" move lines
nmap - ddp
nmap _ ddkkp
```

Save this to `.o.vimrc` or `.obsidian.vimrc` in the root of your vault directory. 

Then you need the [vimrc-support](obsidian://show-plugin?id=obsidian-vimrc-support) plugin to make this work. It defaults to looking for `.obsidian.vimrc` but for some reason I default to `.o.vimrc`. 


> [!warning] `.vimrc` and Sync
> It's worth noting that Obsidian sync will not, by default, sync your `.vimrc` files. You can override this by telling it to sync unsupported file types, but by default when you sync to a new device you will not have your vim config.

If hidden files are being annoying you _can_ just name the file `o.vimrc` which will make it not hidden, but won't make Sync copy it by default.
