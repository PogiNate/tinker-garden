# Tailscale

![[Tailscale.jpeg|100]]

| Property | Value                                    |
| -------- | ---------------------------------------- |
| homepage | https://tailscale.com/                   |
| license  | mixed, open source with prop. components |
| pricing  | free for "home lab" use                  |

This is a very interesting one. The goal of Tailscale is to create a "mesh <abbr title="Virtual Private Network">VPN</abbr> that allows you to reliably connect all your devices without going through a lot of configuration. Needless to say I love this idea. I often need to connect to one of my home machines. 

It also streamlines things like file backups and using a <abbr title="Network Attached Storage">NAS</abbr>, as you can always reach said NAS even when you are on a corporate network or just on someone's café wi-fi. 

So this isn't a "privacy VPN" like Nord or whatever, where all you care about is your traffic appearing to come from somewhere else in the world, this is an actual _Virtual Private Network_ where you want to connect multiple machines together privately, regardless of the network hardware. 

My early IT days self would have gone _wild_ for this. 

But this should let me stop using things like [[36.02 Resilio Sync|Resilio Sync]] and [[36.03 Synology Drive|Synology Drive]] as I will be able to mount drives directly with a less messy connective layer. Both Sync things have given me stress recently.
