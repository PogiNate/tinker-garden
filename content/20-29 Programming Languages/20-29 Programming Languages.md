Realistically I only use a few programming languages on a recurring basis. So each one gets a category. Aren't they lucky? 

For languages that have "sub-languages" the sub-language will just be included in the main language's directory. For example, Squeak and Pharo are both sub-languages of SmallTalk, TypeScript is a sub-language of JavaScript, etc.
